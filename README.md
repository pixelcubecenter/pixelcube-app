## Features

- **Shop**: browse the full PixelCube Center catalog
- **Cart & Wishlist**: one tap away from the bottom bar
- **Sign in with Google**: fast, secure login to your account
- **Three languages**: English, Arabic (العربية) and Kurdish (کوردی)
- **Offline detection**: tells you when your connection drops instead of showing a blank page

## Download

### Option 1 — Komi Store (recommended, gets automatic updates)

1. Install [Komi Store](https://f-droid.org/packages/zed.rainxch.githubstore/).
2. Search for **pixelcube-app** (or `pixelcubecenter/pixelcube-app`).
3. Tap **Install**. Komi Store will notify you when a new version is released.

### Option 2 — Direct APK

1. Go to the [latest release](https://github.com/pixelcubecenter/pixelcube-app/releases/latest).
2. Download **`PixelCube-Center-v*.apk`** under *Assets*.
3. Open the file on your phone and allow *Install unknown apps* when asked.

## Requirements

| | |
|---|---|
| Android version | 7.0 (API 24) or newer |
| Architectures | arm64-v8a, armeabi-v7a, x86_64 (universal APK) |
| Package name | `com.pixelcubecenter.app` |

## Verify the APK

Every release is signed with the same PixelCube Center key. You can check it with `apksigner verify --print-certs`:

```
SHA-256: D6:A0:51:15:CE:BE:07:A8:8D:5A:BE:6E:C9:9D:3B:6E:A3:71:AF:56:E9:04:3E:FB:F5:99:B5:6B:DF:FF:90:FF
```

If the fingerprint doesn't match, don't install the file.
